# 咔嚓

SillyTavern 楼层生图扩展。点击消息旁的相机，输入提示词或选择预设，按需贴参考图、勾选本楼层或 Char / User 样貌，再点生成。开始后面板自动收起，可以继续聊天，出图后点右下角查看。

## 安装

在酒馆的「安装扩展」填入 `https://github.com/GDOG0622/kacha`。已安装旧版的用户可在扩展管理里更新，然后刷新页面。只需安装前端扩展，咔嚓和胡萝卜的服务端插件均为非依赖项。

## 设置

- **自定义**填 OpenAI 兼容 API 基础地址和 Key。点「连接」拉取全部模型，选择模型后保存组合。浏览器需要能跨域访问该服务的模型和图片接口，以及服务返回的图片链接。
- **NovelAI** 填 Key，选模型后保存。下拉包括 Anime V3、Furry V3、V4、V4.5 和 V5。参考图走 Vibe Transfer，从 V4 起首次编码参考图可能消耗 Anlas。
- 自定义服务走 `/images/generations`，加入参考图时走 `/images/edits`。
- 「参考本楼层」复用酒馆原生生图的 Last Message 模板，通过独立的聊天模型请求将选中的消息提炼成逗号分隔的视觉标签。使用 NovelAI 时也读取原生生图的提示词前缀和负面提示词，并追加单张画面和无文字要求。

主面板的输入框用于本次画面。勾选「参考本楼层」时，填写的内容作为本次楼层提词要求。

直接添加的参考图和预设里的参考图主要用于画风。Char / User 样貌里的参考图用于人物外观。

## 保存与分享

- 在「设置」新建多套命名的 API 组合，在「生图」下拉切换。服务、URL、Key、模型和当前选择通过酒馆原生文件接口随账号保存。Key 存在扩展的账号文件中，浏览器直连时会读取它。由 0.2.0 更新后，请在当前账号重新保存 API 组合。
- 预设、Char / User 样貌和参考图通过酒馆原生文件接口随账号保存。预设可保存正向画风、负向提示词和参考图，并可导入或导出为 `.kacha.json`。
- 页面首次打开面板时读取账号数据；之后切换楼层会立即显示已读取的数据，并在后台检查更新。后台同步期间可以操作，若服务器内容变化而面板已在使用，当前编辑内容会保留，重新打开面板即可读取更新。读取失败可以在面板中重试。保存时会核对服务器上的数据并回读确认。如果提示服务器数据已变化，先复制尚未保存的编辑内容，再重新打开面板读取最新数据。
- 出图只存当前浏览器的 `localStorage`。在「记录」点开或删除。空间不足时优先淘汰旧图，单张超出容量时可在当次面板里预览。
- 主面板会在当前浏览器记住预设、勾选项和提示词。临时添加的参考图在当前页面里保留，刷新后可重新添加。
