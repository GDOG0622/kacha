# 咔嚓

SillyTavern 楼层生图扩展。点击消息旁的相机，输入提示词或选择预设，按需贴参考图、勾选本楼层或 Char / User 样貌，再点生成。

## 安装

在酒馆的「安装扩展」填入 `https://github.com/GDOG0622/kacha`。已安装旧版的用户可在扩展管理里更新，然后刷新页面。只需安装前端扩展，咔嚓和胡萝卜的服务端插件均为非依赖项。

## 设置

- **自定义**填 OpenAI 兼容 API 基础地址和 Key。点「连接」拉取全部模型，选中即保存。浏览器需要能跨域访问该服务的模型和图片接口，以及服务返回的图片链接。
- **NovelAI** 填 Key，选模型后保存。下拉包括 Anime V3、Furry V3、V4、V4.5 和 V5。参考图走 Vibe Transfer，从 V4 起首次编码参考图可能消耗 Anlas。
- 自定义服务走 `/images/generations`，加入参考图时走 `/images/edits`。
- 「参考本楼层」会用当前酒馆的聊天接口，把对应消息提炼成生图提示词。

## 保存与分享

- 服务 Key 和模型配置保存在当前浏览器。由旧版更新后，需要重新保存 Key。
- 预设、Char / User 样貌和参考图通过酒馆原生文件接口随账号保存。预设可导入或导出为 `.kacha.json`。
- 出图只存当前浏览器的 `localStorage`。在「记录」点开或删除。空间不足时优先淘汰旧图，单张超出容量时可在当次面板里预览。
